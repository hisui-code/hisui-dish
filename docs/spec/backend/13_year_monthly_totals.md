# Year Monthly Totals API

## 対象 API

- `GET /api/v1/year_monthly_totals`

## 目的

指定年の月ごとの食事量合計を返す。

## 用語

- `month`
  - 年の何月か
- `total`
  - その月の食事量合計
- `eat_finished`
  - 食事が終わったと確定したイベント

## 計算方法

### `month`

年の何月かを返す。

- `1` から `12` までを返す

### `total`

その月の食事量の合計を返す。

- `eat_finished` のみを集計対象にする
- `eaten_grams` を JST の月ごとに合計する
- 1月から12月まで固定で返す
- データが無い月は `0` を返す

## 日付の扱い

- DB は UTC 保存
- 月ごとの区切りは JST 基準で決める
- JST の年初から年末までを UTC に変換して検索する

## 0件の時の返し方

- 1月から12月まで返す
- すべての `total` は `0`

## 異常系

- `year` が不正な形式なら `400`
