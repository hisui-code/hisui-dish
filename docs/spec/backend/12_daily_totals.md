# Daily Totals API

## 対象 API

- `GET /api/v1/daily_totals`

## 目的

指定月の日ごとの食事量合計を返す。

## 用語

- `day`
  - 月の何日か
- `total`
  - その日の食事量合計
- `eat_finished`
  - 食事が終わったと確定したイベント

## 計算方法

### `day`

月の何日かを返す。

- `1` から月末日までを返す

### `total`

その日の食事量の合計を返す。

- `eat_finished` のみを集計対象にする
- `eaten_grams` を JST の日ごとに合計する
- 1日から月末日まで、すべての日を返す
- データが無い日は `0` を返す

## 日付の扱い

- DB は UTC 保存
- 日ごとの区切りは JST 基準で決める
- JST の月初から月末までを UTC に変換して検索する

## 0件の時の返し方

- 月内の全日を返す
- すべての `total` は `0`
