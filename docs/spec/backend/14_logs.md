# Logs API

## 対象 API

- `GET /api/v1/logs`
- `DELETE /api/v1/logs/{log_id}`

## 目的

食事ログの一覧取得と削除を行う。

## 用語

- `logs`
  - 画面に表示する食事ログ一覧
- `recordedAtIso`
  - ログが記録された時刻
- `grams`
  - そのログで食べた量
- `eat_finished`
  - 食事が終わったと確定したイベント

## 一覧取得

### 計算方法

#### `logs`

対象月の食事ログ一覧を返す。

- `eat_finished` のみを一覧対象にする
- JST の対象月で絞り込む
- 新しい順に返す
- 同時刻なら `id` 降順で返す
- `recorded_at` は JST の ISO 形式へ変換する

## 削除

### 動作

指定した食事ログ 1 件を削除する。

- `eat_finished` のログ 1 件を対象にする
- 指定 `id` のレコードを削除する
- 対象が無い時は `404`
- 削除できた時は `204`
