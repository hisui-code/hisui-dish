# Frontend Pages

## 目的

各画面が何を表示し、どんな操作を受け付けるかをまとめる。

## Login

- メールアドレスとパスワードを受け取り、ログインを行う
- ログイン失敗時はエラーメッセージを表示する
- ログイン成功時は認証済み画面へ進む
- 受け取った `auth_token` を保持し、以後の API 呼び出しで使う

## Dashboard

- 今日の食事イベントを表示する
- 今日の合計量を表示する
- 残量を表示する
- 日次、週次、月次、年次の集計を表示する
- 表示に必要な複数の集計値をまとめて扱う

## Logs

- 食事ログ一覧を表示する
- 月、キーワード、時間帯の条件で絞り込む
- 不要なログを削除する
- 日ごとにグループ化して表示する

## Settings

- DeviceSettings を表示する
- DeviceSettings を更新する
- 保存結果や競合を利用者へ伝える
- 取得失敗時は再読み込み導線を出す

## Users

- 管理者がユーザー一覧を確認する
- 管理者がユーザーを追加、更新、削除する
- 管理者以外には利用不可として扱う

## 管理者限定画面

- `Users` は管理者だけが使える
- 一般ユーザーが `/users` を開いた時は `403` 画面を表示する
- サイドバーの表示も `isAdmin` を使って切り替える
