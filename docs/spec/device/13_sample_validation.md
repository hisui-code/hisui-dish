# Device が食事判定に使えない異常値を除外する

## 目的

判定に使う前に、おかしな値や急に大きく変わった値を除外する。

## 入力

- `grams`
- `net_grams`
- 直前の有効な値

## 出力

- 有効サンプル
- 無視するサンプル

## 処理内容

1. 小さすぎる重さを除外する
2. 大きすぎる重さを除外する
3. 直前の有効な値と比べて、急に大きく変わりすぎた値を除外する
4. ただし、その変化がしばらく続く時は、新しい基準として受け入れる

## なぜ必要か

- 配線ノイズや読み取りミスを、そのまま判定へ使いたくないため
- ただし、皿の置き直しのような継続する変化は受け入れる必要があるため

## 補足

- 実装では、この「急に大きく変わった値」を `jump` と呼ぶ
