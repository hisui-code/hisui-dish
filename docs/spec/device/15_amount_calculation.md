# Device が 1 セッションの食事量を算出する

## 目的

1 セッションで何 g 食べたかを算出する。

## 用語

- `start_weight`
  - 食事開始候補に入った時に固定した、開始直前の安定した重さ
- `min_weight`
  - その食事中に記録した、一番軽い重さ
- `eaten_grams`
  - `start_weight - min_weight` で求める食事量

## 入力

- 食事が始まる直前の基準の重さ
- 食事中に記録した重さ

## 出力

- `eaten_grams`

## 処理内容

1. 待機中の安定した重さを短く保持しておく
2. 食事開始候補に入った時、その時点の安定した重さを `start_weight` として固定する
3. 食事中に一番軽かった重さを `min_weight` とする
4. `start_weight - min_weight` を `eaten_grams` とする
5. 微小差分なら破棄する

## なぜ必要か

- ログ保存や集計は「どれだけ減ったか」を単一値で持つ必要があるため
- 微小差分まで保存するとノイズが増えるため
- 待機追従用の基準をそのまま使うと、接触スパイクの影響を引きずりやすいため
- 食べ始めた瞬間の値だけを使うと、開始が少し遅れた時に食事量が少なく出るため
