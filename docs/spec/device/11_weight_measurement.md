# Device が重量変化を検知し、判定用の重量値を作る

## 目的

センサーが返す値を、そのままではなく「重さ」として使える形に直す。

## 入力

- センサーが返した値
- キャリブレーションで決めた値

## 出力

- `grams`
- `runtime_zero`
- `net_grams`

## 処理内容

1. センサーから値を読む
2. その値を、キャリブレーションで決めた値を使って重さ `grams` に変える
3. 起動した直後の重さをしばらく見て、平均を `runtime_zero` にする
4. `grams` から `runtime_zero` を引いて、`net_grams` を作る

## なぜ必要か

- センサーが返す値は、そのままでは何 g か分からないため
- 「今どれだけ重いか」だけでなく、「起動した時からどれだけ変わったか」も見たいため
- 皿あり / 皿なしの判定では、起動時に皿が載っていても使えるように `grams` を使う必要があるため
