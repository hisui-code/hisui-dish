# Device が皿あり / 皿なしを判定する

## 目的

皿を置いた時と外した時を見分けて、皿がある時だけ食事判定を動かす。

## 入力

- `grams`
- 時刻

## 出力

- `NO_BOWL`
- 皿あり状態

## 処理内容

1. `grams` が「皿あり」とみなす重さ以上かを見る
2. 一定時間続いたら皿ありと判定する
3. `grams` が「皿なし」とみなす重さ以下かを見る
4. 一定時間続いたら皿なしへ戻す
5. 皿なしへ戻る時は、待機追従用の基準と開始判定用の履歴をクリアする

## なぜ必要か

- 皿を置く、外す時の重さの変化を、食事と区別するため
- 皿がない時まで食事判定すると、誤判定しやすいため
